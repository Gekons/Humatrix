1. The essentials in three sentences

You have your own chat server. Your messages are end-to-end encrypted — the server only holds scrambled text. Section 7 says where the limits are.

Nobody can simply sign up. Whoever is meant to be in needs an invitation, and you send it (or someone you allow to).

You are connected to the worldwide Matrix network: your people can also write to people on other servers.

2. First login

  1. Open https://chat.example.com in the browser.
    Username and the password from the box above. The browser is fine for the initial setup; for everyday use the app is better (section 4).
  2. Change your password right away.
    In the settings under "Account". Pick something long — a sentence beats a short jumble.
  3. Set up the second factor. See section 3 — please don't skip it.

3. Second factor for your admin account

Your account can create accounts, block them and change passwords. A single password in front of that is not enough. The second factor takes two minutes.

  1. Install an authenticator app. Recommended: Aegis (Android) or Ente Auth (both systems). Your phone's password app can usually do it too.
  2. Open https://service.example.com and there "Second factor".
  3. Scan the QR code shown with the app.
  4. Type in the six-digit code the app shows. Only then does it go live — so you cannot lock yourself out while setting it up.

If the phone gets lost

Then you cannot get into the admin page without help. Get in touch with First Last — they can reset the second factor on the server.

4. The app on the phone

You don't need an app from us — you use a ready-made one from the stores. That is deliberate: this way the person who built the app is not the one who runs the server.

  1. Install the app. Recommended: FluffyChat — looks friendly and is the easiest. If you prefer something faster, go for Element X (the variant with the X).
  2. Enter the server. The app asks for it. This goes in: example.com
  3. Log in with username and password.
  4. Compare emoji. When you add a second device, both show the same little pictures. If they match, confirm. That is the check that nobody is sitting in the middle.

5. Inviting people

At https://invite.example.com — all your people log in there, not just you.

  1. Log in with the usual chat account.
  2. Choose where the person should go — for example "Family" or "Sports club". They then get an invitation into that room right away and are not left with an empty app.
  3. Press "Create invitation".
  4. Send the link — via WhatsApp, SMS, whatever you like. There is a button for it.

The invited person opens the link, installs the app and enters the code. Done. An invitation is valid for 14 days and works exactly once. This is what it looks like on their end:

Who may invite how many people?

You decide that at https://service.example.com. For each person you can enter any number — 0 means "may not invite anyone", and there is a tick box for "unlimited". New accounts get a default, which you also set there.

There you also see who brought in whom. So it stays traceable through whom someone joined.

7. What the operator can see — and what not

This should be out in the open, so you can pass it on to your people.

Your messagesNo. The server only holds scrambled text. The keys are exclusively on your devices.
Photos and filesNo. Also encrypted.
Who, when, with whomYes. That a message went and between whom is visible on the server — the content is not.
Disk usage, account namesYes. That is part of running it.
Restore historyNo. Without your keys that is not possible — not for us either.
Set a new passwordYes. That would allow taking over an account and reading messages from then on — old messages stay locked, and all devices of the account are logged out in the process, so you would notice.
Chat in the browserThe browser chat at https://chat.example.com is served by the operator themselves and could be altered — there the encryption does not protect against them. If you want to rule that out, use the app from the store (section 4).

8. Phone gone — what then?

Because nobody but you has the keys, nobody can bring the history back either. So take two precautions beforehand:

  1. Log in a second device — tablet or computer. That is the best backup, because it works without you doing anything. If the phone gets lost, nothing is gone.
  2. Turn on the key backup when the app asks for it, and keep the recovery key safe. Don't dismiss it — this one step decides whether the history survives a change of device.

9. When something doesn't work

"Too many attempts"The server slows down after a few failed attempts. Wait a minute, then it works again. The password is usually right.
Code is not acceptedIs the time on the phone correct? Turn on automatic time.
Red warning sign in the chatDon't guess — it means an unverified device. Ask the sender, or ask First Last.
Call doesn't connectHave both sides switch from Wi-Fi to mobile data once. If it keeps happening, report it.
